# SQL Server Database Course — Route Academy

## 📌 Project Overview

This repository contains practical SQL Server exercises completed as part of the Database course at **Route Academy**. The project uses the **Northwind database** to practice SQL queries, database objects, transaction management, data synchronization, analytical functions, and query optimization.

## 🎯 Topics Covered

### 1. DDL & Database Design
- Creating and altering tables.
- Identity columns, primary keys, and constraints.
- Database object lifecycle.

### 2. SQL Fundamentals
- Scalar functions and `CASE` expressions.
- Filtering, sorting, and data type conversion.
- Handling `NULL` values.

### 3. Joins & Aggregations
- `INNER JOIN` and `LEFT JOIN`.
- Self joins.
- `UNION` and `INTERSECT`.
- Aggregate functions with `GROUP BY` and `HAVING`.

### 4. Advanced Querying
- Subqueries and correlated subqueries.
- Common Table Expressions (CTEs).
- Local temporary tables and table variables.
- Anti-joins and `NOT EXISTS`.

### 5. Database Objects
- Views.
- Stored procedures.
- User-defined functions.
- Indexed views and materialized view concepts.

### 6. Transactions & Error Handling
- ACID properties.
- `TRY...CATCH`, `COMMIT`, and `ROLLBACK`.
- Savepoints and transaction management.
- Blocking and deadlocks.

### 7. Triggers & Auditing
- Audit log table creation.
- `AFTER UPDATE` and `AFTER DELETE` triggers.
- Trigger safety and `INSTEAD OF` trigger concepts.

### 8. Data Synchronization & Incremental Loading
- Staging tables.
- `MERGE` for data synchronization.
- Watermark-based incremental extraction.
- Delete handling, soft deletes, and hard deletes.
- Idempotency.

### 9. Window Functions & Analytics
- `RANK()` and `DENSE_RANK()`.
- `LAG()` and `ROW_NUMBER()`.
- `NTILE()` for grouping data into quartiles.
- Running totals using `SUM() OVER()`.

### 10. Performance & Query Optimization
- Clustered, non-clustered, composite, and covering indexes.
- Included columns and key lookups.
- SARGable predicates.
- Actual execution plan analysis.
- Database statistics and selectivity.
- B-Tree index concepts and partition elimination.

## 🛠️ Technologies

- Microsoft SQL Server
- T-SQL
- SQL Server Management Studio (SSMS)
- Northwind Sample Database

## 📂 Repository Contents

- `EndToEndSql_DE.sql` — SQL script containing practical exercises and solutions across the course topics.

## 🚀 Learning Outcomes

Through this project, I strengthened my ability to write SQL queries, work with database objects, manage transactions, synchronize data, apply analytical window functions, and understand database performance and query optimization.

This project represents an important step in my learning journey toward **Data Engineering**.
